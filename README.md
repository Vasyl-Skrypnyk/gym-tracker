# Железо

Бесплатный локальный PWA-дневник тренировок. Работает на iPhone и компьютере, не требует аккаунта и сохраняет данные только в браузере пользователя.

## Возможности

- недельные тренировочные программы со своими днями, упражнениями и числом подходов;
- запуск готового тренировочного дня без повторного добавления упражнений;
- подстановка и сравнение результатов с прошлым выполнением того же дня;
- активная тренировка с весом, повторениями и таймером отдыха;
- собственные упражнения и готовая базовая библиотека;
- история, редактирование и удаление тренировок;
- личные рекорды и графики прогресса;
- экспорт и импорт резервной копии;
- офлайн-режим после первого открытия.

## Локальный запуск

Запусти встроенный локальный сервер (установка зависимостей не нужна):

```powershell
npm start
```

После запуска открой адрес, который покажет команда. Обычное открытие `index.html` как файла не подходит для Service Worker.

## GitHub Pages

В репозитории открой **Settings → Pages**, выбери **Deploy from a branch**, затем ветку `main` и папку `/(root)`.

Данные тренировок не попадают в репозиторий: они хранятся в IndexedDB на конкретном устройстве. Регулярно используй экспорт резервной копии в настройках приложения.
